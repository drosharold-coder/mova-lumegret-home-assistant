# MOVA brand assets

This directory contains the brand images used by Home Assistant for the `mova_lumegret` custom integration.

## Source and permission

The artwork is based on the official MOVA/LumeGret logo supplied for this community project. MOVA granted permission to use the official logo for the community Home Assistant integration on GitHub and HACS.

This permission covers the branding used to identify this community integration. It does **not** make the integration an official MOVA product, and it does not imply that MOVA supports or endorses the integration's code.

## Home Assistant files

- `icon.png` - 256 x 256 square icon, derived from the M mark in the supplied wordmark
- `icon@2x.png` - 512 x 512 hDPI icon
- `dark_icon.png` - 256 x 256 light-on-dark icon
- `dark_icon@2x.png` - 512 x 512 hDPI light-on-dark icon
- `logo.png` - official MOVA wordmark for light backgrounds
- `logo@2x.png` - hDPI wordmark
- `dark_logo.png` - light-on-dark wordmark
- `dark_logo@2x.png` - hDPI light-on-dark wordmark

The images are PNG files with transparency and are trimmed/resized for Home Assistant's local custom-integration brand image support.
